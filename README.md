# CAD Scrapers

Python-based tools for automated discovery, enrichment, and verification
of CAD companies and engineering specialists.

## China CAD Companies

Automated discovery and verification of CAD-related companies
using public web sources and Azure OpenAI.

Features:
- Company discovery and web scraping
- Azure OpenAI integration
- Website availability and relevance verification
- Contact information enrichment
- Deduplication and data filtering
- Parallel processing and rate-limit handling
- SQLite caching and Excel exports

## Russian CAD Candidates

Automated discovery and verification of CAD developers
and engineering specialists.

Features:
- Multi-platform candidate discovery
- GitHub and GitLab API integration
- AI-powered contact enrichment
- Candidate profile and email verification
- SQLite-based persistent state
- Excel reporting and data processing

## Technologies

Python, Azure OpenAI, REST APIs, Requests, Playwright,
SQLite, GitHub API, GitLab API, Web Scraping.

## Security

API credentials must be configured through environment variables.
Collected databases and private contact information are not included.
